# Khwaaish AI Shopping Assistant

Mobile-first conversational AI grocery app built with Next.js 15, React 19, TypeScript, Tailwind CSS, Zustand, Framer Motion, Lucide, and Shadcn UI components.

## Core Experience

- AI chat-based shopping flow with suggestions and recommendations
- Product cards with add-to-cart and quantity stepper
- Cart bottom sheet with animated transitions
- Checkout, order success, and tracking screens
- Mood Shopping presets for personalized bundles

## Development
